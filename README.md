# CampusPath — College Placement Portal

Beginner-friendly responsive static website made with HTML, CSS and JavaScript. It is distinct from a Student Management System because it focuses on placement vacancies, eligibility information, deadlines and application tracking.

## Features
- Responsive dashboard and opportunity cards
- Search by company, role, location or skills
- Filter Full-time and Internship roles
- View package/stipend, deadline, sample CGPA and branch eligibility
- Track applications and update statuses
- Remove or clear tracked applications
- Browser localStorage persistence

## Run locally
1. Extract this ZIP.
2. Open `index.html` in Chrome or Edge.
3. To edit, open the folder in VS Code and change `index.html`, `style.css` or `script.js`.

## Publish with GitHub Pages
1. Create a public repository, e.g. `college-placement-portal`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open repository Settings → Pages.
4. Select **Deploy from a branch**, branch `main`, folder `/(root)`, and click Save.
5. Wait for deployment and open the URL GitHub displays.

## Important
Company names, vacancies, packages, deadlines and eligibility rules are fictional sample data, not real job postings. Applications are only tracked in the current browser and are not submitted to employers. This is a front-end academic prototype without a backend or shared database.
